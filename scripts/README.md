# Scripts

This directory contains the tooling used to refresh upstream sources (Sarasa + Nerd Fonts), patch Nerd Fonts `font-patcher`, build release assets, and verify published artifacts.

## Typical workflows

### Build release assets locally

```bash
scripts/refresh-upstream.sh
scripts/build-release-assets.sh
ls -la dist/
```

### Check upstream updates (CI helper)

This checks the latest upstream release tags and refreshes `scripts/font-patcher` when needed.

```bash
scripts/bump-upstream-versions.sh --dry-run
```

### Verify a published release uses expected upstream versions

```bash
scripts/verify-release-assets.sh --tag v2.4.0
```

## Prerequisites

- `gh` (GitHub CLI)
- `python3`
- `fontforge`, `python3-fontforge`
- `fonttools` (`ttx`) for inspection/verification
- `p7zip` (`7zr`), `unzip`, `tar`, `jq`

On Ubuntu/Debian:

```bash
sudo apt update
sudo apt install -y fontforge python3-fontforge python3-fonttools p7zip jq unzip
```

## Script index

### `refresh-upstream.sh`

Downloads pinned upstream assets into `tmp/` and regenerates `scripts/font-patcher` from Nerd Fonts `FontPatcher.zip` plus the local patch (`font-patcher.patch`).

- Reads version pins from `scripts/upstream-versions.env`
- Downloads:
  - Sarasa Term SC (hinted + unhinted) from `be5invis/Sarasa-Gothic`
  - Nerd Fonts `FontPatcher.zip` from `ryanoasis/nerd-fonts`
- Output:
  - `tmp/sarasa/`, `tmp/sarasa-unhinted/`, `tmp/FontPatcher/`
  - `scripts/font-patcher` (generated)

Usage:

```bash
scripts/refresh-upstream.sh
```

### `build-release-assets.sh`

Builds both hinted and unhinted release artifacts and copies them to `dist/`.

- Input:
  - `tmp/sarasa/` and `tmp/sarasa-unhinted/` (from `refresh-upstream.sh`)
  - `tmp/FontPatcher/` resources + `scripts/font-patcher`
- Output:
  - `dist/SarasaTermSCNerd*.{tar.gz,7z}`

Usage:

```bash
scripts/build-release-assets.sh
```

Environment overrides:

- `SARASA_DIR_HINTED` / `SARASA_DIR_UNHINTED`: override Sarasa input directories
- `FONT_PATCHER_DIR`: override FontPatcher resources dir
- `WORK_DIR`: override build working directory (defaults to repo root)

### `build`

Core build driver invoked by `build-release-assets.sh`. It patches all Sarasa `.ttf` in `sarasa/` using `./font-patcher` and generates the packaged outputs under `sarasa-nerd/`.

Usage (normally not called directly):

```bash
SARASA_DIR="sarasa" bash -xeu scripts/build
```

### `verify-release-assets.sh`

Downloads a release’s `*.ttf.tar.gz` assets, extracts a small sample, then verifies:

- Embedded upstream version strings (Sarasa / Nerds / ttfautohint) from the font `name` table
- Hinting-related table differences between hinted/unhinted builds (`cvt ` / `fpgm` / `prep`)
- Current upstream latest release tags for comparison

Usage:

```bash
scripts/verify-release-assets.sh --tag v2.4.0
scripts/verify-release-assets.sh --tag v2.4.0 --workdir tmp/verify-v2.4.0 --keep
```

### `bump-upstream-versions.sh`

CI-oriented helper that:

- Checks latest upstream release tags for Sarasa and Nerd Fonts
- Updates `scripts/upstream-versions.env` when new upstream versions exist
- Runs `scripts/refresh-upstream.sh` to regenerate `scripts/font-patcher`

Usage:

```bash
scripts/bump-upstream-versions.sh --dry-run
scripts/bump-upstream-versions.sh
```

### `upstream-versions.env`

Central place to pin upstream versions and asset names used by `refresh-upstream.sh`.

### `apply-font-patcher-patch.py` / `sarasa_helpers.py`

Applies `font-patcher.patch` to an upstream Nerd Fonts `font-patcher` in a more robust way than relying on brittle `git apply` hunks.

You normally don’t need to run these manually; `refresh-upstream.sh` calls them.

### `font-patcher.patch`

Local patch applied on top of upstream Nerd Fonts `font-patcher` to match this project’s needs (glyph selection/ranges, fixes/workarounds).

### `font-patcher`

Generated output of `refresh-upstream.sh`.

Do not edit this file directly. Edit `font-patcher.patch` instead, then re-run `scripts/refresh-upstream.sh`.

### `otf2otc.py`

Helper used during packaging to build TTC collections from TTF inputs.

### `update-formula-sha256.sh`

Utility for updating SHA256 values in a Homebrew formula/cask to match the latest GitHub release artifacts.
